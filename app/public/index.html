Nginx Reverse Proxy

Cổng tiếp nhận duy nhất, tự ký chứng chỉ HTTPS, Rate limiting, chặn tấn công và gán Security Headers.

Port 80 (HTTP) Port 443 (HTTPS) SSL/TLS
Kiểm Tra HTTPS (443)

PostgreSQL & pgAdmin

Cơ sở dữ liệu quan hệ lưu trữ dữ liệu phòng, khách hàng, đơn đặt với nguyên tắc Least Privilege (hotel_user).

PostgreSQL 16 Internal: 5432 pgAdmin: 5050
Mở pgAdmin 4
🔥

Prometheus Giám Sát

Thu thập số liệu thời gian thực từ Node.js App, Nginx Exporter, Postgres Exporter, cAdvisor và Node Exporter.

Port 9090 Metrics Exporters cAdvisor 8080
Mở Prometheus UI
📊

Grafana Dashboards

Bảng điều khiển trực quan hóa metrics hệ thống, ứng dụng, container và cơ sở dữ liệu thời gian thực.

Port 3001 Auto-Provisioning 3 Dashboards
Mở Grafana (3001)
📜

Loki & Promtail (LogQL)

Hệ thống gom log tập trung từ Nginx và Web App. Truy vấn nhanh chóng các sự kiện nghiệp vụ và mã lỗi HTTP.

Port 3100 Promtail Agent LogQL Queries
🛡️

BẢO MẬT & HARDENING

• 3 Isolated Networks (Frontend, Backend, Monitoring)

• Least Privilege DB User (hotel_user)

• Non-root User Container (UID 10001)

• Nginx Security Headers & SSL Rate Limiting
